# توازن — متجر الثياب السودانية

واجهة أولية لمتجر ويب عربي باتجاه RTL، متجاوبة مع الهواتف، ومصممة لعرض منتجات توازن في المعادي.

## تشغيل محلي

افتح `index.html` في المتصفح، أو شغّل خادم ملفات ثابتة من مجلد المشروع، مثل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ما يعمل في هذه النسخة

- عرض منتجات تجريبية مع تصفية حسب النوع والبحث.
- سلة مشتريات تحفظ الاختيارات في المتصفح.
- نموذج بيانات الطلب وتجهيز رسالة واتساب تشمل العناصر والمجموع والعنوان.
- تصميم عربي متجاوب ورسوم SVG محلية للمنتجات.

## يلزم استكماله قبل استقبال طلبات حقيقية

1. في `app.js` استبدل المنتجات والأسعار والمقاسات والصور التجريبية ببيانات المحل الفعلية.
2. ضع رقم واتساب المحل بصيغة دولية، أرقام فقط، في `STORE_CONFIG.whatsappNumber`.
3. الدفع الإلكتروني **غير مفعّل** في هذه النسخة. يلزم اختيار بوابة دفع مناسبة، إنشاء حساب تاجر، وبناء خادم خلفي ينشئ جلسة الدفع ويتحقق من نتيجة الدفع بتوقيع/إشعار البوابة. لا تضع مفاتيح سرية في `app.js` أو الواجهة الأمامية.
4. حدد رسوم ومناطق ومواعيد التوصيل، وسياسة الاستبدال، ثم اعرضها بوضوح قبل الإطلاق.
5. اربط نموذج الطلب بقاعدة بيانات وخدمة إدارة آمنة للمخزون والطلبات إذا كان المحل سيعتمد عليه تشغيليًا.

الأسعار، المنتجات، وبيانات الاتصال أمثلة توضيحية وليست عرضًا تجاريًا فعليًا. لا تُعلن الدفع الإلكتروني كخيار متاح حتى اكتمال ربط بوابة الدفع والخادم الخلفي واختبارهما.
